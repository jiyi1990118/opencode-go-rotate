## 1. 审计方法

1. 基线实测：`bun test tests/go-rotate-plugin.test.ts` → **89 pass / 313 expect / 2.16s**。
2. 提取 `go-rotate.ts` WEB_HTML（L944-1592，重构前版本）作为断言字符串的真实来源，逐条核对断言的目标字符串出现位置。
3. 对照新 IA（`docs/信息架构规划-管理端.md` §2.2 区块树 + §5.2 HTML 骨架）与兼容红线（§1.3 + `审计报告` §7 白名单）判定每个断言的「重构后状态」。
4. 判定标准：
   - **保留**：元素 id/函数/onclick/文案在 IA 骨架中标注 `[保留]` 或未列入改动清单 → `toContain` 必然通过。
   - **语义保留但结构变**：元素在，但实现方式可能改变拼接/渲染方式 → 断言字符串可能消失。
   - **计划移除**：IA 明确删除 → 断言必然失败。

## 3. P1-1 XSS 修复影响专项

### 3.1 唯一受影响断言：`data-edit="`（L631）

P1-1 要求修 `refresh()` 内三处用户可控字段 innerHTML 拼接（`k.name` / `k.key` / `h.detail`）。实现方式有两种，直接影响本断言：

| 实现方式 | `data-edit="` 字符串 | 断言结果 |
|---|---|---|
| 方案 A：保留字符串拼接 + 统一 `escapeHtml()` 转义值 | `'<button data-edit="' + escapeHtml(k.name) + '" …'` → 字符串保留 | ✅ 通过 |
| 方案 B：改 DOM API（`createElement` + `setAttribute` + `textContent`） | `btn.setAttribute("data-edit", k.name)` → 字符串消失 | ❌ **失败** |

**同步建议（两方案通用）**：把 L631 `expect(html).toContain('data-edit="')` 改为 `expect(html).toContain("data-edit")`（不带引号，`setAttribute("data-edit", …)` 也匹配）——无论实现方选 A/B 均通过，且仍能锁定「编辑按钮绑定存在」。

### 3.2 其余断言不受 XSS 修复影响

- `title="编辑名称 / key 值"`（L632）：静态文案。方案 A 保留于拼接；方案 B 出现于 `setAttribute("title", "编辑名称 / key 值")` 参数——两种实现下字符串均在 JS 源码中 → 断言恒过。
- 函数名 / id / onclick / API 路径 / CSS class：XSS 修复不改这些。

### 3.3 若实现方同时修 P1-2（webOff 定时器）与 P1-3（概览错误可见）

- P1-2：`webOff()` 加 interval 清理，函数体改动，无现有断言引用 → 不影响。
- P1-3：`showErr/showMsg` 若改目标元素（如新增全局错误区），现有断言未锁定 `#msg` 的 className 逻辑 → 不影响。新增断言见 §4.6。

## 6. 风险提示（测试视角）

1. **`toContain` 是弱断言**：现有 72 条 WEB_HTML 断言全部是「字符串存在于整个 WEB_HTML」——无法验证元素「在哪个区块」或「是否可交互」。本次重构的 A 组改动（元素搬家）恰好全部漏过现有断言网，**必须靠 §4 #10-12 三条位置型断言（`indexOf` 比较）补上**，否则「日志卡搬家失败」这类回归不会被测试捕获。
2. **B4 copyToken 改造的隐性回归**：若实现方把 `copyToken` 改成不依赖 `gwToken` 的「直接复制」时顺带删了 `navigator.clipboard.writeText`（例如换成别的方式），现有 L941 断言会挂——属预期内，实现时保持 clipboard 调用即可。
3. **CSP 断言需与实现对齐**：若后端加 CSP 头而测试按 meta 标签断言（或反之），会假失败。§4 #1 两种思路都给出，主线程实施时以实际实现为准，两条保留其一。
4. **启动序列断言（L673）是隐性耦合**：它锁定 5 个初始调用的**精确顺序**。重构若仅为美观调整顺序（如把 `switchNav` 提前）也会挂——这属于「断言过强」，但 IA 规划未计划改动，保持现状即可；若实现方顺手重排，需同步该断言为「分别断言 5 个函数存在」而非单字符串。
