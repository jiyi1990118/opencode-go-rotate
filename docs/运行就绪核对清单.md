# go-rotate + zen-gateway · 新装运行就绪核对清单

> 面向「从零到跑通」的一页核对清单。每一行都有**期望输出**，照做即可。
> 审计依据：2026-08-16 沙箱全链路实测（见 [`docs/审查报告-新装审计.md`](审查报告-新装审计.md)），macOS（系统 bash 3.2）环境。

## 0. 安装前环境检查

| 检查项 | 命令 | 期望输出 |
|---|---|---|
| macOS 版本 | `sw_vers -d` | macOS 12+（本清单按 macOS 实测；Linux 见 systemd 参考） |
| Node ≥18 | `node --version` | `v18.x` 或更高（zen-gateway 需要） |
| Python 3 | `python3 --version` | `Python 3.x`（CLI/install.sh 需要） |
| curl | `command -v curl` | `/usr/bin/curl` 或路径 |
| bun（可选） | `command -v bun` | opencode 自带 bun；`go-rotate web` 独立启动需要 |

> ⚠️ macOS 系统 bash 是 3.2（`bash --version`），对中文提示紧邻 `$变量` 有已知展开 bug（见「已知坑 1」）。功能不受影响。

## 1. 安装（二选一）

### 方式一：一行命令（推荐，拉取 GitHub 最新版）
```bash
curl -fsSL https://raw.githubusercontent.com/jiyi1990118/opencode-go-rotate/main/install.sh | bash
```
### 方式二：本地（仓库已 clone / 下载）
```bash
bash install.sh
```

**期望输出**（两种方式一致）：
```
[go-rotate] 插件 => ~/.config/opencode/plugins/go-rotate.ts
[go-rotate] CLI  => ~/.local/bin/go-rotate
[go-rotate] 已创建默认配置 ~/.config/opencode/go-keys.json
[go-rotate] 安装完成！
```
（若 `~/.local/bin` 不在 PATH，会提示已追加到 `~/.bashrc` / `~/.zshrc`，**新终端生效**。）

**验证产物**：
```bash
ls -l ~/.config/opencode/plugins/go-rotate.ts ~/.local/bin/go-rotate ~/.config/opencode/go-keys.json
# 期望：三个文件都在（go-rotate 有 x 权限）
cat ~/.config/opencode/go-keys.json
# 期望：{"provider_id": "opencode-go", "cooldown_minutes": 300, "current": "", "keys": []}
```
幂等：**重复运行 install.sh 不会覆盖已有配置**（输出「配置已存在，跳过」）。

## 2. 初始化配置

```bash
go-rotate init            # 交互式：粘贴 key，回车结束
# 或命令行添加：
go-rotate add act1 sk-xxxx
go-rotate add act2 sk-yyyy
```

**期望输出**：每个 key 添加后自动探测状态（`✅ 可用` / `⚠️ key 无效` 等），最后
`✅ 配置完成！当前 key: "act1" 已同步到 auth.json。`

## 3. 验证轮换链路（无需真实请求的部分）

```bash
go-rotate status          # 期望：current key + 各 key 冷却状态
go-rotate set act2        # 期望：switched to key "act2" and synced auth.json
go-rotate next            # 期望：rotated to key ... and synced auth.json
go-rotate cooldown act1 30; go-rotate cooldown act1 clear   # 手动冷却/清除
go-rotate check act1      # 真实探测（每次约 1 token，可用 key 会消耗少量额度）
```

验证 auth.json 已同步：`grep key ~/.local/share/opencode/auth.json` → 与当前 key 一致。

## 4. 真实 opencode 请求验证轮换

```bash
opencode run -m opencode-go/hy3 "Reply with exactly: OK"   # 期望返回 OK
tail -5 /tmp/opencode-go-rotate.log   # 期望看到 go-rotate loaded 日志
```
配额耗尽时（401/402/429）应自动轮换并在日志出现 `✅ 轮换到 key "..."`。

Web 管理界面：启动 opencode 后访问 **http://localhost:8899**（期望：管理页面 + `/api/status` 返回 JSON）。

## 6. 已知坑速查

| # | 坑 | 现象 | 规避 |
|---|---|---|---|
| 1 | **macOS bash 3.2 中文紧邻变量 bug** | 管理脚本/安装脚本中「中文全角字符紧邻 `$VAR`」的提示信息丢值/乱码（如 `健康检查通过 ` 后 URL 丢失） | 功能不受影响，仅提示显示问题；可换 zsh 运行或忽略 |
| 2 | **`ANTHROPIC_AUTH_TOKEN` 劫持**（真实 `~/.claude/settings.json` 里是 `PROXY_MANAGED`） | claude code 忽略 `ANTHROPIC_BASE_URL`，直连上游 | 切网关前 `unset ANTHROPIC_AUTH_TOKEN`，或改用 `ANTHROPIC_API_KEY` |
| 3 | **EADDRINUSE / 手动实例占端口** | 之前 `nohup node gateway.mjs &` 手动跑过 → 18888 被占，LaunchAgent KeepAlive 反复重启 | 先 `pkill -f gateway.mjs`，再 `bash install.sh zen-gateway` |
| 4 | **launchd 首次 spawn 慢** | `zen-gateway start` 等待健康检查（最多 15s） | 属正常；`zen-gateway logs` 看进度 |
| 5 | **codex 默认发 web_search 工具** | 网关 400 `Upstream request failed` | config.toml 顶层加 `web_search = "disabled"` |
| 6 | **8899 端口被占** | Web 管理界面打不开 | 插件会自动识别自家实例「不再重复启动」；或 `go-rotate web off` 关自动启动 |

## 7. 卸载（按需）

```bash
bash install.sh zen-gateway-uninstall -y       # 或走安装脚本（含删 gateway.mjs/管理脚本）
bash install.sh uninstall -y                   # 卸载插件 + CLI + go-keys.json（auth.json 保留）
```
**期望**：对应文件删除，`~/.local/share/opencode/auth.json` 始终保留。
