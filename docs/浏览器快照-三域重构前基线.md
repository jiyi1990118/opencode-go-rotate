## Key 管理块（nav-keys）

- 新增卡 `keys-add-card`：`#new-name` + `#new-key` + `addKey`。
- `#check-hint`（检测所有 key 提示）+ `#keys-empty`（空态横幅）。
- 表格卡 `keys-table-card`：`min-width:860px`，`<thead>` **5 列：名称 | Key | 状态 | 健康 | 操作**，`<tbody id="tbody">`；`#msg`（隐藏消息区）。

### 每 key 操作按钮（tbody 行内，data-* 委托绑定 onclick）

| data-* | 标签 | 调后端 |
|---|---|---|
| `data-set` | TUI 使用 | `POST /api/current {name}`（TUI 域，同步 auth.json） |
| `data-set-gw` | 网关使用 | `POST /api/current {name, domain:"gateway"}`（不写 auth.json） |
| `data-cooldown` | TUI 冷却 / TUI 清冷却 | `POST /api/cooldown {name, minutes}`（清=0） |
| `data-cooldown-gw` | 网冷却 / 网清冷却 | `POST /api/cooldown {name, minutes, domain:"gateway"}` |
| `data-window` / `data-window-clear` | 窗口 / 清窗 | 独立冷却窗口 min（prompt） |
| `data-edit` | 编辑 | 双 prompt 改 name/key → `/api/keys/update` |
| `data-del` | 删除 | confirm → `/api/keys/delete`（danger 类） |

- min-width 860px + @media 720px 双断点兜底（操作列 7 按钮不换行）。
