## 0. 设计目标

管理端已有 `:root`（深色默认）+ `html[data-theme="light"]`（浅色覆盖）双主题 + `#theme-btn` 右上角
切换 + `localStorage("gr-theme")` 记忆。Team B 把**按钮体系**从「硬编码色值」收口为
「按钮专用语义变量 `--btn-*`」，使：

1. 按钮配色跟随主题切换（深/浅各自一套），不再散落硬编码 hex。
2. 语义类名（`primary/danger/ghost/sm/loading`）与现有 HTML 按钮 **100% 保持**（31 个既有按钮零改动）。
3. 对比度达标（浅色下 danger 文字用深红 `#b91c1c`，spinner 用深圈，避免浅底不可读）。

---

## 1. 设计 Token（变量命名规范）

命名统一 `--btn-<语义>-<属性>`（spinner 一族为 `--btn-<语义>-spin / -spin-top`）。

### 1.1 命名约定（重要：中性与语义两套 hover 写法不同）

| 族 | 示例 | hover 写法 |
|---|---|---|
| **中性**（无语义） | `--btn-bg / --btn-bd / --btn-fg` | **后缀**：`--btn-bg-hover / --btn-bd-hover / --btn-fg-hover` |
| **语义**（primary/danger/success） | `--btn-primary-bg / -bd / -fg` | **前缀**：`--btn-primary-hover-bg / -hover-bd / -hover-fg` |
| ghost | 仅 `--btn-ghost-fg` + hover | `--btn-ghost-hover-bg / -hover-fg`（无底色变量） |
| spinner | `--btn-spin / --btn-spin-top`（中性），`--btn-primary-spin / -spin-top`（语义） | - |

> ⚠️ 注意：中性 hover 用**后缀**，语义 hover 用**前缀**（`hover-bg` vs `bg-hover`），这是既成实现，
> 维护时勿混用。

### 1.2 类名绑定

- 只认类 `primary / danger / ghost / sm / loading`（及组合 `.danger.loading`），变量不新增任何类。
- **中性默认**：普通 `button` / `.actions button` 走 `--btn-bg/--btn-bd/--btn-fg`。
- **`.sm`**：只改几何（现有 `height:26px; padding:0 8px; font-size:12px; border-radius:5px`），不涉颜色。
- **`.nav-btn.active`**（导航高亮）同样复用 `--btn-primary-*`，保持全局品牌一致。
- 额外保留 `--btn-success-*`（预留：暂无 success 主按钮，为将来预留命名空间）。

## 4. 使用指南（维护/新增按钮时）

1. **能复用类就不要造按钮**：普通操作默认 `button`，主操作 `class="primary"`，危险 `class="danger"`，
   次级 `class="ghost"`，行内小按钮 `.sm`（或 `.actions button`）。
2. **颜色一律变量**：新增样式不得硬编码按钮色 hex，必须引用 `--btn-*`（spinner 用
   `--btn-*-spin / -spin-top`）。配色随主题由变量体系保证。
3. **hover 命名**：中性用后缀（`--btn-bg-hover`）、语义用前缀（`--btn-primary-hover-bg`），见 §1.1。
4. **尺寸**：`.sm` 只动几何（height/padding/font-size/radius），不写死颜色。
5. **改动验证**：
   ```bash
   cd /Users/jary/serverTools/go-rotate
   bun build go-rotate.ts   # 编译通过
   bun test tests/go-rotate-plugin.test.ts   # 107 pass / 0 fail（含按钮类名契约 + --btn-* 深/浅两套断言）
   # 语义哨兵：grep -n --btn- go-rotate.ts 应见 :root + html[data-theme="light"] 两套
   ```

## 5. 与既有红线的关系

- **HTML/类名红线**：`primary/danger/ghost/sm/loading` 及其组合 `danger.loading` 原样保留，现有按钮
  HTML 零改动（Team B 只改 CSS 变量 + `button` 规则）。
- **id/class 白名单**（`docs/审计报告-管理端现状基线.md` §7 必须保留的元素）不受影响；本规范只
  **增加** `--btn-*` 变量与重写按钮规则。
- **兼容**：非按钮控件（徽章 `.b-*` / `.badge`）仍用既有 `--success-soft/--warning-soft/--danger-soft`
  等，不并入按钮变量族，避免跨组件耦合。

## 6. 实现核对结论（2026-08-17）

1. ✅ 变量名沿用 `--btn-*`，两套（`:root` + `html[data-theme="light"]`）均已落地。
2. ✅ 浅色 danger 文字采纳深红 `#b91c1c`（非契约早前建议的 `#dc2626`，实际更收敛于品牌红系）；
   浅色 spinner `--btn-spin-top: #16181c` 深圈可见。
3. ✅ `--btn-success-*` 已预留（无在用按钮）。
4. 契约与实现的唯一偏差：早前契约假设 `--btn-border/--btn-text/--btn-spinner-*`，实际为
   `--btn-bd/--btn-fg/--btn-*-spin`；且中性 hover 后缀 vs 语义 hover 前缀并存。已记录于
   `docs/测试同步-网关使用方式与按钮主题.md` §4.2 命名对齐表。
