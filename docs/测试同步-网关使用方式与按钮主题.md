### 2.3 与新增内容的潜在冲突（Team A/B 新增断言注意事项）

- **CSS 类名 vs DOM 属性同名**：`gw-config-grid` 既是 CSS 规则名（在 `<head>`，位于 nav-settings 之前）
  又是元素 class（在 nav-settings 内）。做**位置断言**必须用 `class="gw-config-grid"`（DOM）而
  非裸 `gw-config-grid`（CSS 首次出现早于 nav-settings），否则位置断言误判（本任务已踩坑并修正，
  见 §4 落地说明）。
- **`127.0.0.1:18888` 已存在**（L1331），Team A 使用方式卡需复用同一文案。新增断言不要写
  `.not.toContain`，只写正断言。
- **复制函数命名**：既有惯例为 `copyToken`（异步）。Team A 的新复制函数建议命名为
  `copyUsage(idx)` 或 `copyUsage(preId)`；若实际命名不同（`copyUsageSnippet` 等），微调断言即可。
