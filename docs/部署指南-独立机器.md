# 独立部署指南：无 opencode 机器上的 zen 免费网关

> 2026-08-18 写入。目标：在没有安装 opencode 的机器（Linux/macOS）上，仅凭网关单文件 + opencode 账号 key，把 opencode zen 免费套餐（`opencode.ai/zen/v1`，7 个免费模型）暴露为 OpenAI / Anthropic / Responses 兼容网关，供 claude code / codex / cursor / 自研程序使用。

## 1. 可行性结论

**可以。** 网关唯一运行时依赖是 Node ≥ 18；与 opencode 本体的两个耦合点都已解耦：

| 耦合点 | 机制 | 无 opencode 时行为 |
|---|---|---|
| User-Agent | `resolveUpstreamUA`：`ZEN_UPSTREAM_UA` env → `opencode --version` 探测 → 回退 `opencode/1.18.18`（官方 UA） | 自动回退官方 UA，与装了 opencode 的机器一致；建议显式设 `ZEN_UPSTREAM_UA` 锁定 |
| 鉴权 | 只读 `go-keys.json` 中的 `sk-` key（opencode 账号 API key，账号面板可拿） | 与 opencode 安装完全无关 |
| 套餐 | `gateway-config.json` 的 `plan` 字段 | `plan=zen` → `https://opencode.ai/zen/v1` + 默认 `hy3-free` + 7 个免费模型 |

**跨平台（Windows 支持自 2026-08-18 完善）**：网关本体（`zen-gateway/gateway.mjs`）纯 Node ≥ 18，三平台一致；常驻服务按系统自动识别——Linux `systemd --user` / macOS `launchd` / Windows `计划任务 schtasks`（登录自启，无需管理员）。一键安装：macOS/Linux `install.sh`，Windows `install.ps1`（PowerShell）。CLI `go-rotate gateway {start|stop|restart|status|logs}` 内部按平台分发，三平台命令一致。opencode 插件/CLI 本身也对 Windows 就绪（`go-rotate add/next/check` 等纯 Python 跨平台）。

免费档特性（与机器无关的上游策略，见 Phase 21/24）：

- 免费模型：`big-pickle` / `deepseek-v4-flash-free` / `mimo-v2.5-free` / `hy3-free` / `laguna-s-2.1-free` / `nemotron-3-ultra-free` / `nemotron-3.5-lightning-free`（`GET /v1/models` 动态拉取）。
- **zen 免费档自动轮换已禁用**（2026-08-18）：同设备 UA/频率限流与账号无关，轮换无效反而误伤冷却——`plan=zen` 时配额/鉴权错误（401/402/CreditsError 等）一律**透传不轮换、不冷却、不计数**；`FreeUsageLimitError` 本就透传（Phase 24）。`plan=go`（付费）保留自动轮换（配额耗尽换 key 有效）。手动轮换（CLI `gateway next` / Web）不受影响。
- 付费模型别名（`gpt-4o-mini` 等）在 zen 档自动回退默认 `hy3-free`（Phase 21 修复）。
- `hy3-free` 是推理模型：`max_tokens` 过小时 `content:null` + `finish=max_tokens`；网关自动放大重试一次（Phase 24，`ZEN_AUTO_MAX_TOKENS=0` 关闭）。

## 2. 前提

- Node.js ≥ 18（`node -v` 确认；Ubuntu 建议 `apt install nodejs` 或 nvm 装 LTS）。
- 一个 opencode 账号的 API key（`sk-` 开头；无 opencode 也能在 opencode 账号设置页生成）。
- 目标机器能访问 `https://opencode.ai`（上游）。

## 3. 目录布局（约定 `/opt/zen-gateway`，root 部署）

```text
/opt/zen-gateway/
├── gateway.mjs            # 单文件程序（唯一程序文件）
├── config/
│   ├── go-keys.json       # key 池（网关共用，与 go-rotate 同格式）
│   └── gateway-config.json# 网关配置（plan/token）
└── logs/                  # 日志输出目录
```

## 4. 安装与配置

**一键安装（推荐，单用户常驻）**：本机装 Node ≥ 18 后跑一次即可——程序 + 默认配置 + 常驻服务（Linux `systemctl --user` / macOS launchd）一次性就绪，安装即用：

```bash
curl -fsSL https://raw.githubusercontent.com/jiyi1990118/opencode-go-rotate/main/install.sh | bash -s -- zen-gateway
zen-gateway status          # 应显示 running
go-rotate add k1 sk-你的key  # 填入 opencode 账号 API key
go-rotate gateway plan zen  # 切 zen 免费档（默认 go 付费档）
zen-gateway restart
```

> 如需**多用户/加固生产**（专用低权限用户 zen-gw + `/opt/zen-gateway` + 仅 systemd），按下方手动方式。

```bash
sudo mkdir -p /opt/zen-gateway/config /opt/zen-gateway/logs
sudo cp gateway.mjs /opt/zen-gateway/

# --- go-keys.json：key 池（多 key 自动轮换） ---
sudo tee /opt/zen-gateway/config/go-keys.json > /dev/null <<'EOF'
{"provider_id":"opencode-go","cooldown_minutes":300,"current":"k1","current_gateway":"k1",
 "keys":[{"name":"k1","key":"sk-你的key","cooldown_until":null,"cooldown_until_gateway":null}]}
EOF

# --- gateway-config.json：plan=zen + 访问 token ---
sudo tee /opt/zen-gateway/config/gateway-config.json > /dev/null <<'EOF'
{"plan":"zen"}
EOF
sudo chmod 700 /opt/zen-gateway/config
```

配置说明：

- `go-keys.json` 与 go-rotate 完全同构：`current_gateway` 网关域当前 key，`cooldown_until_gateway` 网关域冷却，`cooldown_minutes` 每 key 独立冷却窗口。配额耗尽（`CreditsError` 等）自动轮换下一个未冷却 key 并重试一次——**仅限 `plan=go` 付费档**；`plan=zen` 免费档自动轮换已禁用（同设备限流与账号无关，透传不轮换）。免费档限流（`FreeUsageLimitError`）任何套餐均不轮换。
- `gateway-config.json` 仅 `plan` 必填：`"zen"`（免费档）或 `"go"`（opencode-go 订阅档，上游 `opencode.ai/zen/go/v1`，默认 `hy3`，26 个模型）。**token 不写文件也可**，用下节 env 注入更安全。

## 5. 常驻服务

### 5.1 Linux（systemd，推荐）

```ini
# /etc/systemd/system/zen-gateway.service
[Unit]
Description=zen-gateway (opencode zen -> OpenAI/Anthropic/Responses gateway)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=zen-gw
WorkingDirectory=/opt/zen-gateway
Environment=NODE_ENV=production
Environment=ZEN_CONFIG=/opt/zen-gateway/config/go-keys.json
Environment=ZEN_GATEWAY_CONFIG=/opt/zen-gateway/config/gateway-config.json
Environment=ZEN_GATEWAY_PORT=18888
Environment=ZEN_GATEWAY_HOST=0.0.0.0
Environment=ZEN_GATEWAY_TOKEN=换成你自己的强随机token
Environment=ZEN_UPSTREAM_UA=opencode/1.18.18
Environment=ZEN_LOG_FILE=/opt/zen-gateway/logs/gateway.log
Environment=ZEN_USAGE_FILE=/opt/zen-gateway/logs/usage.jsonl
# Environment=ZEN_PROBE_INTERVAL_MIN=15   # 可选：配额主动探测轮换
# Environment=ZEN_AUTO_MAX_TOKENS=0       # 可选：关闭截断自动重试
Restart=always
RestartSec=3
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

```bash
sudo useradd -r -s /usr/sbin/nologin zen-gw
sudo chown -R zen-gw:zen-gw /opt/zen-gateway
sudo systemctl daemon-reload
sudo systemctl enable --now zen-gateway
sudo systemctl status zen-gateway
```

### 5.2 macOS（launchd）

无 opencode 机器上同样可用 launchd（模板在 `zen-gateway/launchd/com.go-rotate.zen-gateway.plist`，用 python3 替换 `__NODE_BIN__` / `__GATEWAY_MJS__` 等占位符后放 `~/Library/LaunchAgents/`，env 键补上 `ZEN_UPSTREAM_UA` / `ZEN_GATEWAY_HOST` 等）。简易 nohup 方式：

```bash
mkdir -p ~/.local/share/zen-gateway ~/.local/share/zen-gateway/logs
cp gateway.mjs ~/.local/share/zen-gateway/
# 配置同上（路径换 ~/.local/share/zen-gateway/config/）
nohup node ~/.local/share/zen-gateway/gateway.mjs >> ~/.local/share/zen-gateway/logs/gateway.log 2>&1 &
```

### 5.3 Windows（计划任务 schtasks）

无需管理员权限（用户级计划任务，登录时自启）。一键安装：

```powershell
# PowerShell 运行（含 opencode 插件 + CLI + 网关服务；服务器无 opencode 加 -GatewayOnly 只装网关）
powershell -ExecutionPolicy Bypass -File install.ps1
# 仅网关：
powershell -ExecutionPolicy Bypass -File install.ps1 -GatewayOnly
```

安装内容：
- 拷贝 `gateway.mjs` → `%USERPROFILE%\.local\share\zen-gateway\`
- 创建默认 `go-keys.json`（`%USERPROFILE%\.config\opencode\`）+ `gateway-config.json`（ascii 无 BOM）
- 生成 `zen-gateway.cmd` 包装脚本（设置 `ZEN_LOG_FILE`/`ZEN_USAGE_FILE`，以正确引号启动 node gateway.mjs）
- 注册计划任务 `com.go-rotate.zen-gateway`（`/SC ONLOGON` 登录自启 + `/Run` 立即启动，无需管理员）

管理（等价跨平台 `go-rotate gateway` 子命令）：

```powershell
go-rotate gateway status          # running / stopped + 端口 + key 数
go-rotate gateway restart         # 重启（改 plan/token 后生效）
go-rotate gateway logs 100        # 看日志（%USERPROFILE%\.local\share\zen-gateway\logs\gateway.log）
go-rotate gateway plan zen        # 切 zen 免费档
```

验证：`curl http://127.0.0.1:18888/v1/models`。

FAQ：`schtasks /Query /TN com.go-rotate.zen-gateway` 查看任务状态；卸载见 `install.ps1` 头部注释（schtasks /Delete + 删网关目录）。

## 7. 安全

- 默认只绑 `127.0.0.1`；跨机访问必须 `ZEN_GATEWAY_HOST=0.0.0.0` **且**设置 token，否则网关拒绝启动（`ZEN_ALLOW_OPEN_NOSEC=1` 显式绕过，仅限可信内网调试）。
- token 支持多 key（`tokens[]` 数组，`POST /api/gateway/token` 生成 `sk-` 前缀 key），逐 key 吊销。
- 日志含 key 名**不含 key 值**；`/api/gateway/config` 只回 name+冷却，零明文泄漏。
- 建议 systemd 下 `NoNewPrivileges` + 专用低权限用户（上面已含）。

## 10. 常见问题

- **429 FreeUsageLimitError**：免费档上游限流（按 UA/频率），不是 key 问题；网关已透传不轮换。稍后重试或换 `hy3-free` 之外的免费模型。上游限流策略不可控。
- **zen 免费档遇到 401/402/CreditsError 不轮换**：这是刻意设计（同设备 UA/频率限流与账号无关，轮换无效）；错误直接透传给客户端，日志有「🚫 zen 免费档自动轮换已禁用」。如确需换 key，手动 `go-rotate gateway next`。
- **返回 `content:null`**：`hy3-free` 推理模型 `max_tokens` 不足；网关自动放大重试一次，仍空则调大客户端 `max_tokens`（≥2000）。
- **`/v1/models` 需要时间**：启动后异步拉取动态模型表，日志出现「模型表更新」后即就绪。
- **多 key 全部冷却**：healthz `available:0`，请求返回上游配额错误透传；`gateway cooldown <name> clear` 或改 `cooldown_minutes`。
- **上游 401/403**：key 失效或账号受限，检查 `go-keys.json` 的 key 是否仍有效（配额状态会写 `last_status` 到失败 key）。
